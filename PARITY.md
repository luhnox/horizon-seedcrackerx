# Parity with SeedCrackerX 2.16.2

SeedCrackerX 2.16.2 (Minecraft 26.3), 70 Java files, against this port. Nothing is claimed that is not true.

| Status | Meaning |
|---|---|
| ported | written from the Java and checked against it (see "How it is checked") |
| partial | exists, but differs from the Java in a way noted beside it |
| missing | not written |
| n/a | Java or Fabric machinery with no meaning in Rust on Horizon |

## Not 1:1 yet

- **Dungeon and Warped Fungus cracking for 1.17 and older is missing.** It needs LattiCG (a lattice solver). Dungeons of 1.18+ are
  read and give their bits; the older floor-pattern route is read but not lattice-solved, and `WarpedFungus` has no finder.
- **No biome source in the game.** The Java finishes a world seed from biomes through the SeedFinding biome sources. Here the hashed
  seed (every server on 1.15+ sends it) gives the world seed, so the usual route works; the biome search does not run.
- **Tab completion** completes `/seedcracker` only, not its sub-commands. Wrong sub-commands answer with a plain message, not Brigadier's.
- **`BlockUpdateQueue`** (the anti-xray bypass thread for 1.17 and older dungeons) is not written.

## Deliberate differences

- A **decoration plant over an air cell** of a structure counts as air (`short_grass`, `dead_bush`, `short_dry_grass`, `cactus`, ...).
  The Java compares exactly, so one tuft of dry grass in front of a desert pyramid hid it. Measured on a generated world, 2 blocks of 1181.
- A chunk that **changes soon after it arrives** (600 ticks) is given to the finders again. A server sends a chunk whole; Horizon's own
  world finishes a chunk after it shows, with the structures last.
- The **config screen** is the page of the mod in Options > Mods (`/seedcracker gui` opens it), not Cloth Config.
- **Outlines** are Horizon gizmos drawn over everything, not the Java's `NoDepthLayer`.

## How it is checked

- The SeedFinding libraries and SeedCrackerX are compiled with a portable JDK and a fixture of their outputs is compared with the Rust
  (`tests/java_diff.rs`, `tests/data/java_fixture.txt`): seed arithmetic, structure placement, region data, bit counts.
- `tests/cracker.rs` runs the TimeMachine on generated data and finds the seed.
- `tests/finders.rs` places each structure in each orientation and expects the finder to find it.
- Live: finders were run on structures generated by Horizon itself (igloo, shipwreck, swamp hut, jungle and desert temples), with the
  outlines drawn through walls.
